# Riham Blogs' Lorem Ipsum Generator
**Try it out at:** [https://cigarettesprettysmokes.pages.dev/lorem/](https://cigarettesprettysmokes.pages.dev/lorem/)
 
## Overview
 
It's an opinionated web page to generate dummy text with advanced configuration. Based on Cicero's *De Finibus Bonorum et Malorum*, the same Latin passage behind every "Lorem ipsum" you've seen.
 
Choose the type ("Paragraphs", "Sentences", "Words") to set what gets generated. The "Amount" range sets how many, and its maximum changes with type (**50** for "Paragraphs", **100** for "Sentences", **500** for "Words").
 
Enable **Start with "Lorem Ipsum"** to prepend the canonical opening phrase ("Lorem ipsum dolor sit amet, consectetur adipiscing elit"). Open "Advanced" to configure paragraph (or sentence) length, and sentence punctuation.
 
For the "Sentences Per Paragraph" and "Words Per Sentence" inputs, you can specify ranges in several ways. For example, "2-6" (range) means a value is between 2 and 6 units, "5" (fixed) means a value is always 5 units, and "2 5-8" (mixed) means a value is exactly 2 units or between 5 and 8 units.
 
For the "Sentence Ends With" input, specify the punctuation used for sentences. Period (.), question mark (?), exclamation mark (!) are supported. Separate them by a single space. For example, "? !" means a sentence can end with a question mark or an exclamation mark.
 
Use Riham Blogs' [Text Analyzer](https://cigarettesprettysmokes.pages.dev/analyze/) to get statistics (e.g. number of characters, words, etc.) about your generated text. You may also report bugs or request features on Riham Blogs' [Submit Feedback](https://cigarettesprettysmokes.pages.dev/feedback/) page.  
 
 
## FAQs
 
**1. What's "Lorem Ipsum"?**<br>Lorem ipsum is a type of placeholder text commonly used in the graphic, print, and publishing industries for previewing layouts and visual mockups.
 
**2. Is this real Latin?**<br>It isn't necessarily "real" Latin. It's made from words in Cicero's *De Finibus Bonorum et Malorum*, reordered into nonsensical Latin-ish writing.
 
**3. Can I use "Lorem Ipsum" commercially?**<br>Yes, the source passage used for generation is in the public domain, and this web page doesn't require attribution for generated text content.
